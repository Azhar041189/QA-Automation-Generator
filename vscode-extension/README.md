# QA Test Generator

Generate automation tests from manual test cases directly in VS Code.

## Features

- Generate Selenium tests from manual descriptions.
- Integrated with the QA Automation Engine.

## Requirements

- VS Code 1.75.0 or later.

## Extension Settings

This extension contributes the following settings:

* `qa.generateTest`: Trigger test generation.
